## 🌳 О проекте

**JASYL** — это веб-приложение для мониторинга и учёта зелёных насаждений города. Система позволяет:

- Автоматически определять состояние деревьев по фотографиям (AI)
- Ведение цифрового паспорта каждого дерева
- Отображение на интерактивной карте с цветовой маркировкой
- Создание и отслеживание заявок на работы
- Аналитика и прогнозирование
- Работа в офлайн-режиме с последующей синхронизацией

Проект разработан в рамках хакатона и ориентирован на практическое применение в работе городских коммунальных служб.

## 🎯 Функциональность

### Основные возможности

| Функция | Описание |
|---------|----------|
| **🌳 Цифровой паспорт дерева** | Фото, вид, состояние, координаты, история осмотров, рекомендации |
| **🗺️ Интерактивная карта** | Маркеры с цветовой индикацией состояния, фильтрация по статусу |
| **📸 AI-анализ фото** | Автоматическое определение состояния дерева по фотографии |
| **📋 Заявки** | Создание и отслеживание заявок на работы с приоритетами и статусами |
| **📊 Аналитика** | Статистика, прогнозирование, графики распределения |
| **📱 Офлайн-режим** | Работа без интернета с синхронизацией при подключении |
| **🔄 Синхронизация** | Автоматическая синхронизация данных при восстановлении соединения |

### Состояния деревьев

| Статус | Цвет маркера | Описание |
|--------|-------------|----------|
| Здоровое | 🟢 Зелёный | Дерево здорово, не требует вмешательства |
| Сухое | 🟡 Жёлтый | Дерево засохло, требуется удаление |
| Повреждён ствол | 🟤 Коричневый | Ствол имеет повреждения |
| Опасные ветви | 🟠 Оранжевый | Сломанные или опасно нависающие ветви |
| Наклонённое | ⚪ Серый | Дерево наклонено, возможен риск падения |
| Болезнь | ⚫ Чёрный | Признаки заболеваний или усыхания |
| Требует проверки | 🔵 Синий | Требуется дополнительный осмотр |

## 🛠️ Технологический стек

### Frontend
- **HTML5 + Tailwind CSS** — адаптивная вёрстка
- **JavaScript (Vanilla)** — логика приложения
- **Leaflet.js** — интерактивная карта
- **Chart.js** — визуализация данных

### Backend (опционально)
- **FastAPI** — REST API
- **PostgreSQL + PostGIS** — база данных с геопространственными запросами
- **Redis** — кэширование
- **MinIO** — S3-совместимое хранилище изображений

### AI/ML
- **ONNX Runtime** — инференс моделей
- **TensorFlow.js / ONNX Runtime Web** — запуск локальной модели в браузере

### DevOps
- **Docker** — контейнеризация
- **Vercel** — хостинг фронтенда
- **Render.com / Railway** — хостинг бэкенда

## 🚀 Установка и запуск

### Предварительные требования

- Docker и Docker Compose (для локального запуска)
- Node.js 18+ (для разработки)
- Python 3.11+ (для бэкенда)

### Локальный запуск с Docker

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/jasyl.git
cd jasyl

# 2. Запуск всех сервисов
docker-compose up -d

# 3. Открыть в браузере
# Frontend: http://localhost:3000
# API: http://localhost:8000
# API Docs: http://localhost:8000/docs
